# ⚡ CachyOS Rice-Architect — Perfektioniere dein Desktop-Design

Verwandle deinen CachyOS / KDE Plasma 6 Desktop mit wenigen Tastenbefehlen in ein visuelles Highlight.

### 🌟 Features
- **Zweisprachig:** Taste `L` im TUI oder Parameter `--lang en`/`--lang de`.
- **1-Klick Ricing-Presets:** Wende abgestimmte Themes für Starship, Fastfetch, Konsole und Terminals direkt an.
- **Rollback & Backups:** Vollautomatische Backups deiner Dotfiles schützen vor Fehlkonfigurationen.
- **Rice-Doctor:** Überprüft Nerd-Fonts, Terminal-Transparenz und Wayland-Eigenschaften.

### Installation
```bash
git clone https://github.com/Graba92/cachyos-rice-architect.git
cd cachyos-rice-architect
./setup.sh
python3 main.py
```
